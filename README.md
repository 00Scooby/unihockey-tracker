# Unihockey Tracker

Eine Offline-First Progressive Web App (PWA) zur Erfassung von Spielerstatistiken während eines Unihockey-Spiels. Entwickelt für den Einsatz auf Tablets am Spielfeldrand.

## Features
- Offline-Fähigkeit (Erfassung ohne Internetverbindung)
- Automatische Cloud-Synchronisation bei bestehender Verbindung
- Touch-optimierte Zähler für Tore, Schüsse, Pässe und Plus/Minus
- Team- und kaderübergreifend nutzbar

## Tech Stack
- React (Vite)
- Firebase Firestore (Offline-Datenbank)
- Firebase Hosting

## Setup
1. Repository klonen
2. `npm install` ausführen
3. `npm run dev` für den lokalen Server starten
